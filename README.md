# Perfume Shop Management System

A Python desktop application for managing perfume shops and individuals.

## Features

- Add and delete individuals
- Add and delete perfume shops
- Search records
- Store data in text files
- Print selected records
- Graphical user interface
- Object-oriented programming

## Technologies

- Python
- Tkinter
- Object-Oriented Programming
- File Handling

## Project Structure

```text
main_gui.py
fizicka_lica_example.txt
parfimerije_example.txt
README.md
```

## Running the Application

Make sure Python is installed, then run:

```bash
python main_gui.py
```

## Data

Example `.txt` files are included for demonstration and testing.

The example files do not contain real personal data.
